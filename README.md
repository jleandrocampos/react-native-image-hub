# react-native-image-hub

React Native image picker: camera (vision-camera), gallery, and custom cropper

## Installation


```sh
npm install react-native-image-hub
```


## Usage


```js
import { multiply } from 'react-native-image-hub';

// ...

const result = multiply(3, 7);
```
